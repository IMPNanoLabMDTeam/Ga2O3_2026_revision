The DFT data used in the original energy–volume curves in the draft (Fig. 5) were taken from the original GAP dataset, except for the γ-phase configurations. This exception arises because the original GAP dataset does not contain a sufficient number of γ-phase configurations to construct a complete energy–volume curve. For the γ phase, we selected the configuration with the lowest potential energy and generated additional structures by isotropically expanding and compressing this configuration to build the energy–volume curve. These generated configurations were calculated using the same protocol as that adopted for the GAP dataset.

To exclude any possible influence arising from the lack of geometry optimization, we further optimized all configurations shown in Fig. 5 using VASP and subsequently performed another series of single-point energy calculations. The corresponding results are provided in results/1.png, which shows that the differences between optimized and unoptimized configurations are limited.

We then carried out another round of predictions using tabGAP and NEP for the optimized configurations (see results/2.png). The results lead to the same conclusions as those reported in the original draft. This indicates that the geometry optimization has no influence on the main conclusions and further validates the reliability of our VASP calculation protocol.
