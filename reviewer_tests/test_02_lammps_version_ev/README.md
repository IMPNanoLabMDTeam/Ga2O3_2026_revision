To rule out any potential influence of the LAMMPS version, we compiled and used two different LAMMPS versions in this workspace. One corresponds to the version used in the work that originally proposed the GAP dataset, while the other is the version employed in our formal prediction comparisons. Using both versions of LAMMPS, we recalculated the energy–volume curves. The corresponding results are provided in results/3.png. As shown in Fig. 3, no observable differences are found between the two sets of predictions, indicating that the LAMMPS version does not affect the final results.
